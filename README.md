# MarbleRace Studio 🎱

Jogo Android de corridas de bolinhas original, sem anúncios e sem rastreadores. Criado em Java nativo para Android 8+.

## Recursos
- Corridas automáticas com física, obstáculos, classificação e câmera dinâmica.
- Personalize os corredores com PNG/JPG/GIF da galeria (GIF usa quadro estático).
- Busque imagens no Wikimedia Commons diretamente no aplicativo.
- Gera vídeos verticais 9:16 em MP4 para Shorts (sem áudio, adicione música no editor).
- Visual escuro com acentos lima, sem anúncios ou login.

## Instalando pelo celular
Abra a aba **Actions** deste repositório, selecione **Build Android APK** e baixe o artefato `MarbleRace-debug-APK`. Extraia o ZIP para encontrar o `.apk` e instale no Android. A primeira build inicia automaticamente após o envio do código.

## Direitos de uso
Respeite os direitos autorais e as condições de atribuição de imagens importadas ou encontradas na busca. Imagens de personagens de outras empresas não passam a ser livres para uso por estarem na internet.
