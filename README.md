# MarbleRace Studio — v1.1 beta 🎱

App Android original, em Java, sem anúncios, para criar corridas de bolinhas e vídeos verticais. Inspirado na apresentação de corridas coloridas, sem copiar vídeos, marcas ou artes de terceiros.

## Novidades

- Quatro pistas: **Sky Drop**, **Candy Lab**, **Neon Reactor** e **Volcano Rush**.
- Rastros individuais na cor de cada bolinha, com transparência.
- Rebatedores, rotores móveis e faixas de aceleração.
- Nova câmera e interface em estilo de transmissão.
- Buscador de imagens combinando Wikipedia e Wikimedia Commons, com atalhos para Mario, Sonic e Blu.
- Botão **WEB ↗** abre busca de imagens no navegador caso a imagem não exista nas fontes públicas; salve a figura e importe da galeria.
- Imagens PNG/JPG e GIF (primeiro quadro estático).
- Exportação MP4 em 9:16, 720 × 1280 e 30 FPS, sem áudio.

O buscador não garante imagens oficiais de personagens e os resultados podem estar protegidos por direitos autorais. Confira a licença antes de usar ou publicar.

## Instalação no celular

1. Abra a aba [Actions](https://github.com/ViniIsOn/MarbleRace/actions).
2. Abra a execução de **Build Android APK** que mostrar ✅.
3. Baixe o artefato **MarbleRace-debug-APK**.
4. Extraia o ZIP e instale **app-debug.apk** no Android.

Projeto Android Java nativo; SDK 35, Java 17, Gradle 8.9. Não coleta dados para anúncios.
